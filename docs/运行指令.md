# RADARSAT-1 FFT→M2串联（板端人工执行，当前NOT_RUN）

先用候选契约做离线校验；真实运行必须换成有板端证据的VERIFIED FFT/M2契约：

```sh
./ffttest-chain --validate-fft-m2 \
  --input fft_m2_com/fft_input.bin --coeff fft_m2_com/m2_coeff.bin \
  --fft-output fft_m2_com/fft_actual.bin --output fft_m2_com/fft_m2_actual.bin \
  --manifest fft_m2_com/fft_m2_manifest.json \
  --contract hardware_contract.json --m2-contract m2_hardware_contract.json

./ffttest-chain --run-fft-m2 --confirm-fresh-reset \
  --input fft_m2_com/fft_input.bin --coeff fft_m2_com/m2_coeff.bin \
  --fft-output fft_m2_com/fft_actual.bin --output fft_m2_com/fft_m2_actual.bin \
  --manifest fft_m2_com/fft_m2_manifest.json \
  --contract hardware_contract.json --m2-contract m2_hardware_contract.json \
  --timeout-ms 2000 --log fft_m2_com/run-fft-m2-001.log
```

详细门禁、DDR中转语义及回传要求见`docs/fft_m2_chain.md`。

# S2→S5→S7→S10→S2连续模式（不复位PL，当前板测NOT_RUN）

```sh
mkdir -p fft_sequence_output
./ffttest --validate-fft-sequence --sequence-plan fft_sequence_plan.json \
  --output-dir fft_sequence_output --contract fft_modes_hardware_contract.json
sudo ./ffttest --run-fft-sequence --sequence-plan fft_sequence_plan.json \
  --output-dir fft_sequence_output --contract fft_modes_hardware_contract.json \
  --timeout-ms 2000 --log fft_sequence_output/run-001.log
```

真实run前必须以当前bitstream证据闭合契约部署/独占/GPIO/地址门禁；序列中不得复位PL或重载bitstream。
